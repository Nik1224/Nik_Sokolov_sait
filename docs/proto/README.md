# Черновики редизайна BUSINESS

Два варианта одного брифа. На сайт не влияют и в сборку не попадают: лежат в
`docs/`, а Next.js отдаёт наружу только `public/`.

- `business.html` — закреплённый заголовок, под ним сменяются миры заказчика.
- `v2.html` — светлый макет: гигантское слово в обрез, поле дрейфующих кадров,
  наклонённые карточки. Более поздний.

## Как посмотреть

Кадры внутри подключены абсолютными путями (`/media/...`), а такие пути
работают, только когда файл отдаётся из `public/`. Поэтому на время просмотра
черновик туда и возвращается:

```bash
mkdir -p public/proto && cp docs/proto/*.html public/proto/ && npm run dev
```

Открыть `http://localhost:3000/proto/v2.html`. После просмотра убрать обратно,
чтобы черновик снова не мог уехать на боевой домен:

```bash
rm -rf public/proto
```

Если просто открыть файл двойным щелчком, разметка и движение покажутся, а
фотографии — нет.
